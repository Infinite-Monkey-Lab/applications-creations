# 🎨 应用与创意作品

这里收录可以直接体验、安装或试用的应用、桌面工具与创意软件。此仓库负责导航；项目代码、发布和问题跟踪保留在各自的独立仓库。

## 项目列表

- [TodoTree](https://github.com/Infinite-Monkey-Lab/todotree) — 本地优先的 Markdown 桌面任务树。
- [FeiyuCursor](https://github.com/Infinite-Monkey-Lab/FeiyuCursor) — Windows 鼠标指针主题与生成工具。

## 收录字段规范

每个项目条目应链接到独立主页，并说明用途、当前状态、维护者、许可证、演示或下载入口、安装方式和问题反馈入口。未知信息标注“待确认”，不要推测许可证或维护状态。

新增或更新条目时，可复制[项目条目模板](https://github.com/Infinite-Monkey-Lab/.github/blob/main/PROJECT_ENTRY_TEMPLATE.md)。

## 提交项目
