# 应用与创意作品

收录可供用户直接体验或安装的应用、桌面工具与创意软件。

## 项目文件夹

- [TodoTree](projects/todotree/README.md)：本地优先的 Markdown 桌面任务树。
- [FeiyuCursor](projects/FeiyuCursor/README.md)：Windows 鼠标指针主题与生成工具。

项目源代码与提交历史保留在各自的原仓库。分类文件夹说明项目与来源；代码迁入时会另行保留许可、署名与提交历史。

- [TodoTree 原仓库](https://github.com/Infinite-Monkey-Lab/todotree)
- [FeiyuCursor 原仓库](https://github.com/Infinite-Monkey-Lab/FeiyuCursor)

## 新增项目
